# Portfólio React — Felipe Costa Monteiro

Versão em React do meu [portfólio de 16 de agosto de 2026](https://github.com/ofelpys/portfolio-atv). Mantive o fundo escuro, o vermelho, o título centralizado, os botões arredondados, a fonte e a marca da UMC. Atualizei o conteúdo com minha formação, tecnologias e projetos.

## Como executar

É necessário ter Node.js instalado. Depois, no terminal:

```bash
npm install
npm run dev
```

Para gerar os arquivos da versão publicada:

```bash
npm run build
```

## Organização

- `src/App.jsx`: textos, seções e lista de projetos.
- `src/styles.css`: cores, espaçamento e versão para celular.
- `public/`: foto, marca da UMC e fontes.
